### Anotações feitas por mim:
Sprint 1- "Scrum // Dicionário do Programador"

Regras do Scrum = 
- papéis = pessoas, equipe do projeto
	product owner = dono do produto, representante do cliente
	scrum master = líder que facilita o trabalho do time, responsável por não deixar impeditivos, mantém o ciclo do scrum fluindo
	time de desenvolvimento = todas as pessoas envolvidas no projeto, criar versões usáveis do produto

- artefatos = documentação e elementos gráficos 
	backlog = lista de requisitos da aplicação (product backlog ), informações necessárias para finalização de um Sprint (sprint backlog)
	histórias = descritivo claro e resumido
	burndown = gráfico, dados do projeto

- eventos = 
	sprint = ciclo de desenvolvimento com tempo pré-determinado
	sprint planning = planejamento do que deve ser entregue no sprint e qual meta será atingida
	daily scrum = sincronismo das tarefas e planejamento para o próximo dia
