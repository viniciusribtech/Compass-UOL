# Resumo da Sprint 02
## O que aprendi?
    O conteúdo dessa sprint não teve muitos tópicos, mas em compensação, foi bem extenso. 

---
## Primeira Semana:
Na primeira semana, foi introduzido o curso de Python, do básico, como estruturas de repetição, String, números, até o avançado, como interação com bancos de dados. Como eu já tive certo contato com Python em projetos pessoais, boa parte do conteúdo me serviu de revisão dos conceitos que ja conhecia, porém, a parte mais avançada se provou desafiadora, de fato. A orientação a objetos em Python segue o mesmo conceito de qualquer outra POO, mas ainda assim, com diferenças na sua estrutura.
Após o curso de Python, a trilha seguiu com o curso de Ciência de Dados para Iniciantes, tratando exclusivamente de algumas bibliotecas do Python, como Pandas, NumPy, e MatPlotLib. Todos esses conceitos eram novidade para mim e repleto de novos comandos.

---
## Segunda Semana:
Na segunda semana da sprint, foi colocado em prática os conhecimentos teóricos da primeira. Onde tivemos que realizar exercícios do básico ao avançado, finalizando com ETL. E, no fim, realizar o desafio, que, assim como no exercício de ETL, foi preciso ler o arquivo .csv para extrair seus dados e seguir pelas etapas.
